# 可可助手 v1.7 正式发行记录

## 自动毕业配装约束
- 将推荐空幕套装要求的四种驱动形状设为硬约束，每种至少一件；库存不足或无法合法摆放时不输出缺件方案。
- 角色盘面被动对应的驱动型号数量优先于装备词条评分；在该数量相同时再比较词条评分和盘面填充情况。
- 保留库存归属、角色归属、唯一装备、坐标边界与不重叠校验。

## 背包管理与批量筛选
- 新增空幕和驱动块背包管理，可按套装、品质、状态、主属性、副属性及匹配副属性词条数量筛选，并批量选择筛选结果。
- 锁定、解锁、弃置和撤销弃置使用现有内存状态操作；操作确认统一使用可可助手样式的弹窗。
- 弃置后可在游戏分解界面筛选“已弃置”，由用户选择经验材料或倒带材料并确认分解。
- 修正空幕属性筛选池：主属性和副属性分别遵循游戏筛选器可选项；驱动块属性按图鉴数据生成，避免混入空幕或其他槽位属性。

## 构建和发布
- 正式版使用签名更新清单、分块下载校验和隔离解压；具体发行版本、配置修订和产物校验记录随本次发布结果更新。


## 修复记录
- 修复部分 Windows 环境下启动更新检查时缺少 SSL 策略文件，导致启动界面报错的问题；新版程序包和安装器均包含该文件，并由构建脚本核验。
