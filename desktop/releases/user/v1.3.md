# 可可助手 v1.3

## 安装前看清空间
- 安装向导显示程序大小、所选磁盘的可用空间和安装预留空间。
- 更换安装位置后重新检查；空间不足时不能开始安装。
- 预留空间包含下载和解压过程，缺少运行库时也会检查相关磁盘。

## 阵容统一由管理端维护
- 自动配队只使用已维护的完整阵容，不再由用户端临时拼出本地规则候选。
- 持有角色或锁定主C无法匹配时，显示明确提示。
- 仍支持养成信息排序和两队角色去重。

## 角色列表更简洁
- 移除角色后面的“几套适配阵容”显示。

## 更新内容补充
- 更新后启动时，仅展示本次版本的更新内容。
- 左下角“更新内容”可切换查看 v1.0 至今的历次说明。
- 本次补充仍为 v1.3；原版 v1.3 用户需运行新版安装器一次。
