# 可可助手 v1.4

## 双队一起推荐
- 双队模式先检查两套维护阵容能否同时成立，再推荐最多三组完整组合，八名角色不会重复。
- 锁定两位主C时，按锁定顺序分别用于第一队和第二队；只锁一位时，保留第一队核心。
- 点击组合方案，同时切换两队，不再出现第一队已推荐、第二队却为空的情况。

## 无解原因更清楚
- 区分没有第一队候选、没有第二队候选，以及两边阵容都存在但角色冲突。
- 提示最近阵容中尚未勾选的角色或冲突角色，便于调整角色池。

双队优先考虑队伍结构与机制匹配，再参考已填写的养成信息。单队推荐保持原有方式；全部候选仍来自启用的维护阵容。

## 角色选择与图鉴
- 在角色池中勾选、锁定或调整养成后，保留列表滚动位置，方便连续选择。
- 角色图鉴新增“命座”标签，查看完整的觉醒与共鸣效果；切换角色时同步更新。
