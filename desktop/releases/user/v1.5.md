# 可可助手 v1.5

## 角色配装 PLUS
- 新增计算配装和游戏配装入口，按当前账号已读取的角色与装备计算搭配。
- 支持保存角色方案、自动装配已保存方案及拆卸；执行前展示预览，完成后核对并刷新装备状态。
- 配装计算显示搜索预算与结果状态；未证明最优时明确提示，不将有限搜索结果当成绝对最优。

## 读取风险由你选择
- 每次启动后首次进入读取数据，展示 DLL 读取风险提示。
- 风险模式默认关闭，仅本次运行有效；主动开启后才可部署组件、读取全部数据或使用配装页的快捷读取。
- 截图识别与已保存数据查看仍可使用。

## UID 与背包管理
- 原生读取自动识别已登录游戏 UID，截图扫描需手动确认 UID，账号数据分别保存。
- 支持为 UID 设置备注，以及确认删除 UID 和对应原生快照、OCR 批次及截图、配装方案；其他账号保留。
- 调整数据选择框与删除按钮对齐，侧栏角色配装增加 PLUS 标识。

## 手柄扫描采集优化
- 手柄全量扫描不再因待识别截图达到 32 张而停下等待 OCR。
- 截图使用较低压缩的无损 PNG，保留像素，减少保存耗时。
- 移除重复的三秒倒计时，保留切回游戏提示、停止机制及选中后的等待。

升级保留已有本机账号和背包数据。删除 UID 为不可撤销操作，请在确认窗口核对账号。
