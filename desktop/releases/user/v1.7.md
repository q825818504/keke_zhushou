# 可可助手 v1.7

## 自动毕业配装
- 推荐套装所需的四种驱动形状必须全部满足，每种至少一件；缺少装备时不会给出不完整方案。
- 角色盘面被动需要的驱动型号优先级最高。满足被动数量后，再比较装备属性评分和盘面填充情况。

## 背包管理
- 可查看空幕和驱动块，并按套装、品质、装备状态、主属性、副属性和符合条件的副属性词条数量筛选及批量选择。
- 锁定、解锁、弃置和撤销弃置的确认提示改为可可助手样式。
- 弃置后，可在游戏分解界面筛选“已弃置”，再选择分解成经验材料或倒带材料并由游戏完成分解。
- 修正空幕主、副属性筛选选项，并按驱动块图鉴提供驱动属性选项。


## 修复
- 修复部分 Windows 环境中启动检查报错、导致程序无法正常打开的问题。

## V1.7 补充修订 r2：环境诊断
- 环境检测结果会写入本机诊断日志，包括组件文件校验、游戏目录与进程路径、组件模块加载状态、端点枚举结果和 VC++ 运行库状态。
- 端点枚举失败会单独标明，不再和“成功枚举但没有端点”混为一谈；同时检查组件宿主与采集插件是否从当前游戏目录加载。
- 原生连接和各数据类别的读取失败会记录阶段、错误码和耗时，便于提交诊断包后定位问题。
- 诊断包仍不包含背包数据、截图或发布凭据；日志只保存在本机，需用户主动导出和发送。
