# 可可助手 v1.1

- 修复联网启动检查窗口关闭后，进入读取数据或开始原生读取时的 Tcl 线程崩溃；启动检查独立进程运行。
- 新增诊断日志入口：近期功能异常、未正常退出提示、Windows 确认的助手/采集组件/游戏崩溃记录，支持导出脱敏诊断包。
- 联网安装增加安装位置选择及浏览；点击开始安装才下载，安装失败可重试。
- 安装完成可选择创建桌面快捷方式、立即运行；更新与卸载沿用自定义安装目录，个人数据保留。
- 明确 Windows 10/11 x64 支持范围，检查安装空间，适配中文/空格路径与系统重定向桌面。
- 每个程序发行必须提供版本升级说明；说明随签名版本清单及 Gitee 发行页发布。
