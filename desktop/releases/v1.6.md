# 可可助手 v1.6 正式发行记录

## 离线配装与逐步游戏装配
- 角色配装 PLUS 保持原路由，新增独立的「角色配装」标准路由。
- 标准配装页从图鉴角色列表生成候选，排除塔吉多；账号/UID 与 DLL 快照 / OCR 批次保存时间分别选择，UID 不作为读取与计算的必填条件。
- 沿用 v1.5 毕业配装 Worker 和评分逻辑，输入只取所选账号、所选 DLL 或 OCR 快照的装备记录；方案在本机按账号和快照隔离。
- 游戏配装不走 DLL 批量接口，改为复用 OCR 装备筛选、角色识别、逐件拖放及画面复核流程。输入期间要求异环保持前台，并提供停止后续输入。

2026-10-19：用户明确授权发布 1.6 正式版，并同步 GitHub 测试仓库 q825818504/keke_test、正式源码仓库 q825818504/keke_zhushou 及 Gitee Alime17/koko-assistant-update。真实游戏全部场景未完整验收，重复候选装备选择问题按用户要求暂缓。

## 修订 1：离线 DLL 数据与扫描性能
- 支持保存的原生装备来源；保留品质、属性、归属，原生方案按快照时间隔离。
- 鼠标截图队列不再受 32 张 OCR 队列限制；鼠标/手柄均仅排队已持久化文件路径。
- 增量进度计数、独立后台检查点和采集中轻量状态响应，解除整批数据序列化与磁盘 I/O 对输入路径的阻塞。

## 修订 2
- 修正接近末尾的滚动条误判与紫色选中框干扰。
- 新增逐格核对及最多两轮缺块补装，保存复核截图。
- 统一 OCR 百分点与 DLL 小数比例单位；新增目录数值校验、可确定小数点修复及异常值计算隔离。

## 锁定与方案隔离
- PLUS 使用 UID 为角色锁存储键，保护外部角色当前装备，保留自身装备候选。角色卡显示只读红锁，顶栏支持仅当前 UID 全部解锁。
- 普通游戏页隐藏账号及时间选择，仅显示冻结的已保存方案装备资料；执行前校验来源时间。
