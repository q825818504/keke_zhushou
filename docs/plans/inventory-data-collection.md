# 背包数据与读取数据功能计划

## 目标与范围

统一可可助手的数据读取入口，同时将已保存的背包数据独立展示。原生读取无需填写计算器安装路径，OCR保留识别与扫描，不接入单件适配评分。使用手动账号标签；自动游戏UID识别暂缓。

## 模块与运行规则

- 读取数据：选择DLL原生、截图导入、鼠标全量、NEW增量或手柄全量。DLL显示组件检测/主动部署/移除，其他方式显示对应采集表单。
- 背包数据：显示背包、驱动块、卡带、已装备和角色统计；按账号及已保存来源切换，提供详情、筛选、导出及OCR纠错。
- 持久化：同标签DLL成功读取按类别更新原生快照，失败类别保留上次快照；新OCR扫描建立独立批次，重试与纠错更新原批次。不同来源不跨来源合并计数。
- 并发：采集和OCR通过有界队列协作。停止采集后继续处理已保存截图；停止全部保留未识别截图供重试。每批截图独立保存。
- 删除：来源旁二次确认；自动来源删除实际显示来源。原生删除该标签快照与备份，OCR删除指定批次及原图。保护运行任务，保持其他账号/批次，清除被删除批次的页面缓存。
- 发行：取消关于菜单，保留许可通知文件；本地发行目录只保留final/KekeAssistant.exe。Git保留源码、测试、许可与资源清单，排除本机EXE、原生组件二进制、OCR生成权重、玩家数据及开发环境。

## 状态提示规范

沿用苹果界面重视的即时、可理解反馈：成功用低饱和绿色，待处理条件用暖色提醒，错误用红色，连接和处理中用蓝色。颜色始终配合短文字和图形符号，不单靠颜色区分；处理中只有轻量旋转提示，并响应减少动态效果系统设置。组件核对明细保留用户的展开/收起选择，异步刷新不替用户折叠。
