# 攻略阵容批量管理计划

## 目标

让维护者能从现有攻略阵容中一次选中并删除多套，减少逐卡片删除的重复操作。单条复制、启用/停用和删除继续可用。

## 交互范围

- 每张阵容卡提供复选框；工具栏显示已选数量，并支持清空选择。
- “全选当前结果”只选择当前搜索词和状态筛选显示的阵容。
- 搜索或筛选切换时保留已选项目，允许分组查找后统一处理；删除确认框说明当前结果之外的已选数量。
- 未选择时禁用批量删除。删除确认显示总数；用户取消时不修改资料。
- 批量删除后提供一次撤销入口，可恢复整批阵容。
- 移动端工具栏换行；已选卡片有清楚的视觉标记。

## 保存与安全

- 按稳定阵容 ID 管理选择，不依赖卡片位置。
- 批量删除一次写入浏览器本地覆盖，再沿用管理端现有项目资料持久化接口。
- 当前正在编辑的阵容若在删除范围内，删除前先询问是否放弃未保存的修改。
- 若项目写入失败，保留本地修改与整批撤销记录，并说明尚未写入项目。
