# 可可助手抖音介绍视频口播稿

**形式：** 用户端录屏 + 旁白，不露脸  
**建议时长：** 约 2 分钟，实际时长随剪映所选音色和语速略有变化  
**口吻：** 像玩家给同好介绍自己常用的工具；语速自然，少用播音腔，不要句句上扬。

## 可直接粘贴到剪映的口播正文

玩异环查资料，我最烦的就是页面来回切：看完角色技能，还得找配装和材料；想配队，又要翻攻略。你是不是也这样？我就做了个可可助手，把玩家常查的东西放到了一起。今天带你看一圈它现在能做什么。

先看角色页。搜名字，进去能看角色定位、技能机制、推荐配装和养成材料。我准备练谁，就先在这里看技能和配装，再去核对要用哪些材料。

配队这块我觉得挺实用。先选上自己有的角色，它会从已有的攻略阵容里，给你几套候选队伍。想让某个主输出优先上场，可以把他锁定；角色共鸣和有没有专属弧盘，也能帮你调整推荐顺序。要配两队时，第二队会用第一队剩下的人来搭，不会重复。它给的是搭配参考，不会模拟整队伤害。

资料看完，再到图鉴里查装备。弧盘能看效果和调弧变化；空幕能看套装效果，以及四件套需要的驱动块形状；驱动块可以按型号、形状搜索，也能查看不同品质下的主属性成长和副词条。配装时要核对哪项，搜一下就行。

想整理自己账号的数据，也有读取数据和背包数据页。可以用原生读取，或者导入截图识别；要扫背包的话，有鼠标和手柄全量扫描，也能只扫描新增物品。读取完成后，在背包页看统计和详情；截图识别结果不准，还可以检查、修正。第一次用，跟着页面提示一步一步走就行。

好，差不多就是这些。你想先看自动配队怎么用，还是截图识别怎么操作？评论区告诉我，我下一条就从大家最想看的开始拍。觉得这个助手对你有用，记得点个关注。

## 剪映配音与拍摄提示

- 只复制“可直接粘贴到剪映的口播正文”，不要把分镜和节奏说明一起粘进去。
- 建议按段落分别生成配音，段间留 0.3–0.5 秒；开场问句和结尾提问各停半拍。
- 选择自然、偏聊天感的普通话音色，语速可从 0.95–1.0 倍试起；不要加过强的兴奋语气。
- 全程只展示用户端功能。读取数据和背包数据镜头使用演示数据，避免录入真实账号信息。
